# Swiftcash_ATM_System

A desktop-based ATM Management System built in using java Swing for the graphical user interface and MYSQL for robust backend database operations. This project simulates core banking operations including user authentication, cash deposits, withdrawals, balance Enquiries. 

**Features :**
1] Secure Authentication: Login and Signup screens with input validation, secure PIN verification, and user-friendly error popups.
2] Account Management: Real-time balance checking, transaction history tracking, and account details management.
3] Core ATM Operations:
          - Cash Deposits : Seamlessly deposit funds into the linked bank account.
          - Cash Withdrawals : Withdraw money with automated balance checks and limit validations.
4] Modern UI Design : Clean, modern desktop aesthetics achieved using FlatLaf styling, centered window layouts, and rounded border components.

**Technology**
Language : Java
GUI Framework : Java Swing, FlatLaf.
Database : MySQL Workbench
Database Connectivity : JDBC

**How to Run**
1. Open the project folder in IDE(Intellij IDEA).
2. Setup Database: create a database named swiftcash_atm_system in MYSQL and update your local username/password in the connections file.
3. Add the MYSQL Workbench JDBC Driver and FlatLaf JAR files to your projects.
4. Run Login file.
